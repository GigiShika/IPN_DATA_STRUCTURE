📋 Rúbrica de Evaluación

La siguiente rúbrica establece los criterios de evaluación para las actividades y proyectos de la unidad de aprendizaje. Cada criterio tiene un peso porcentual y se califica en cuatro niveles de desempeño. Esta herramienta busca proporcionar una retroalimentación clara y objetiva sobre el desarrollo de las competencias.

Criterio para evaluar 🔰Excelente 🔶Bueno ⚠️Regular ❌Deficiente
Elección de la Estructura (30%) Elige la estructura de datos ideal para resolver el problema de forma óptima La estructura elegida es buena, pero existen alternativas ligeramente mejores. Utiliza la estructura adecuada, pero su diseño no aprovecha los recursos. La estructura de datos no es la adecuada para el problema planteado.
Implementación y Manejo (20%) El estudiante declara todos los elementos que se van a utilizar para la manipular de la estructura de datos Al estudiante le faltaron declara algunos elementos que se van a utilizar para la manipulación de la estructura de datos, generando pequeños errores El estudiante al no declarar los elementos necesarios para la manipulación de la estructura de datos, se presentan fallas lógicas. El estudiante declaro de forma incorrecta los elementos que se van a utilizar para la manipulación de la estructura de datos, por lo que no logra implementarla, desconocimiento total de su funcionamiento,
Funcionamiento del programa (30%) El programa se compila y al ejecutarse realiza lo requerido El programa se compila y al ejecutarse le faltaron algunas operaciones El programa se compila y al ejecutarse No realiza lo requerido El programa no se compilo
Documenta el programa (10%) El estudiante documenta muy bien cómo y por qué funcionan las líneas de código. El estudiante documenta bien pero no detalla cómo funcionan las líneas de código El estudiante no documenta todas las líneas de código El estudiante no documenta el programa
Corrida del programa (10%) El estudiante evidencia en un archivo de PDF que el programa realiza todas las operaciones requeridas, además que en la parte superior aparezca su nombre El estudiante en la evidencia del archivo de PDF no aparece su nombre, pero en la corrida muestra las operaciones requeridas El estudiante en la evidencia en un archivo de PDF aparece su nombre, pero en el código no lo manda a imprimir El estudiante no entregó la evidencia en un archivo de PDF
